### US-157 Chronicle

As the player, I want a warm history of my town, so that I feel attached to it.

- **Points:** 5 (ADR 0107) · **Priority:** Must · **Sprint:** S26
- **Acceptance:** From spec 029
- **Scope (ADR 0107 §13):**
  - **In Phase 3:** An automatic history: the founding, each era, the first child born, a child's first literacy in its family, record harvests, businesses founded and closed, disasters survived, the first festival, the clinic and the road. Warm entries from string templates with the player's names and numbers; a Chronicle sheet in the Menu.
  - **Not in Phase 3:** Illustrations beyond the existing icons.
  - **The spec sets:** Each entry's wording (numbers and wording only; the scope above is decided).

**Tasks**

- [ ] Broken down into tasks when this phase's spec is written (rolling wave, ADR 0019).

### US-158 Almanac

As the player, I want a year-end summary, so that I reflect on my decisions.

- **Points:** 3 (ADR 0107) · **Priority:** Must · **Sprint:** S26
- **Acceptance:** From spec 029
- **Scope (ADR 0107 §13):**
  - **In Phase 3:** At each Winter close, after *Your year*: population, net worth, the year's best return (the business or crop with the best profit over its cost), its costliest loss (the biggest loss line) and a citizen spotlight.
  - **Not in Phase 3:** Comparisons with other players' towns.
  - **The spec sets:** How the spotlight is chosen (numbers and wording only; the scope above is decided).
