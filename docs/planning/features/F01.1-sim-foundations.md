### US-025 Fixed-point numbers

As the developer (Claude), I want a Q31.32 `Fixed` type with exact rounding, so that rates and factors are deterministic on every runtime.

- **Points:** 3 · **Priority:** Must · **Sprint:** S0
- **Acceptance:** Spec 001 AC-1, AC-2

**Tasks**

- [ ] US-025.T1 Implement `Fixed` add, subtract, compare
- [ ] US-025.T2 128-bit multiply with round-half-away-from-zero
- [ ] US-025.T3 Divide via BigInteger with the same rounding
- [ ] US-025.T4 `FromRatio` and exact decimal parsing
- [ ] US-025.T5 Tests `FixedTests.*`

### US-026 Counter-based RNG

As the developer (Claude), I want a SplitMix64 counter-based RNG with fixed stream ids, so that random results never depend on call order.

- **Points:** 2 · **Priority:** Must · **Sprint:** S0
- **Acceptance:** Spec 001 AC-3, AC-4

**Tasks**

- [ ] US-026.T1 Implement `Rng.Next(seed, stream, key, counter)`
- [ ] US-026.T2 Uniform via multiply-high
- [ ] US-026.T3 Weighted pick
- [ ] US-026.T4 Golden values and chi-square tests

### US-027 State hash

As the developer (Claude), I want a canonical 64-bit state hash, so that determinism tests can compare whole states.

- **Points:** 1 · **Priority:** Must · **Sprint:** S0
- **Acceptance:** Used by AC-11 and AC-13

**Tasks**

- [ ] US-027.T1 FNV-1a hasher
