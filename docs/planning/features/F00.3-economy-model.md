### US-013 Seasonal farm cash-flow model

As the developer (Claude), I want a headless model of one founder farm across seasons, so that starting numbers can be tested before the full game exists.

- **Points:** 5 · **Priority:** Must · **Sprint:** S2
- **Acceptance:** The model runs 15 game years in under 10 s and prints seasonal cash flow

**Tasks**

- [ ] US-013.T1 Model crops per season, founder labour, living costs, inputs, trader sales
- [ ] US-013.T2 Read all numbers from `content/` JSON
- [ ] US-013.T3 Print a seasonal summary table

### US-014 Anchor numbers in content

As the developer (Claude), I want rupee-scale anchor prices, wages, land prices and the starting package in data, so that every spec uses the same tuned numbers (ADR 0008).

- **Points:** 3 · **Priority:** Must · **Sprint:** S2
- **Acceptance:** All anchor values live in `content/` and are referenced by specs 002–006

**Tasks**

- [ ] US-014.T1 Wheat, rice, potato, lentil, radish and fruit prices
- [ ] US-014.T2 Day-labour and farm-hand wages per season
- [ ] US-014.T3 Land price per acre by soil (8–15 seasons of an acre's net farm income, ADR 0028)
- [ ] US-014.T4 Starting savings (`StartDef`)
- [ ] US-014.T5 Replace placeholder defaults in specs 002–005 with tuned values (no re-approval needed, ADR 0027)

### US-015 Money-loop checks

As the developer (Claude), I want automated checks that buying and reselling never profits and no input chain creates value from nothing, so that the Phase 0 gate can be proven.

- **Points:** 3 · **Priority:** Must · **Sprint:** S3
- **Acceptance:** Checks run in `dotnet test` and pass

**Tasks**

- [ ] US-015.T1 Buy-resell loop check across all goods and seasons
- [ ] US-015.T2 Input-to-output value check for crops and trees
- [ ] US-015.T3 Add as tests

### US-016 Viability checks

As the developer (Claude), I want a fresh founder to reach a profitable season and a broke founder to recover via day labour, so that the start is fair and nobody gets stuck (ADR 0009).

- **Points:** 3 · **Priority:** Must · **Sprint:** S3
- **Acceptance:** Both checks pass across 1,000 seeds

**Tasks**

- [ ] US-016.T1 Fresh-start bot
- [ ] US-016.T2 Broke-founder bot (no cash, no credit)
- [ ] US-016.T3 Report pass rates
