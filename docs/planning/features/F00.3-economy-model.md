- **US-013 done:** `dotnet run --project tools/Tools.Balancer -- economy [years] [seed]` runs a competent founder-alone bot on the real sim (15 years in about 0.13 s) and prints each season's P&L, cash and net worth, then spec 003 §9's anchor checks. The hand (spec 006) is estimated; produce sells to the trader at the floor until the Sprint 3 market

### US-013 Seasonal farm cash-flow model

As the developer (Claude), I want a headless model of one founder farm across seasons, so that starting numbers can be tested before the full game exists.

- **Points:** 5 · **Priority:** Must · **Sprint:** S2
- **Acceptance:** The model runs 15 game years in under 10 s and prints seasonal cash flow

**Tasks**

- [x] US-013.T1 Model crops per season, founder labour, living costs, inputs, trader sales
- [x] US-013.T2 Read all numbers from `content/` JSON
- [x] US-013.T3 Print a seasonal summary table

- **US-014 done:** every anchor checked for realism (ADR 0008) and pacing (ADR 0028, 0030); moisture and climate weights tuned (spec 002's hook, with a test); land payback measured on an owner-operated acre (ADR 0033: 8.5 seasons); saplings priced with planting. The farm hand's 36,000 a season is spec 006's anchor and moves into content with its loader (Sprint 4)
