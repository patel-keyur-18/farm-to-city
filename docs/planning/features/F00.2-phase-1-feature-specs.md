## Summary

Write and approve specs 002–009 before their implementation sprints, at most 2 per sprint (ADR 0025). Writing order follows what code needs first: 002 and 005 in Sprint 0, 003 and 004 in Sprint 1 (ADR 0027). Specs fix formulas, bounds and placeholder values; the economy model tunes the values in data afterwards, and only formula changes need re-approval (ADR 0027).
