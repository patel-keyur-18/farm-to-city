- **Done (owner, PR #5):** Unity 6.3 LTS (6000.3.26f1), Universal 2D template, iOS platform, bundle ID `com.keyurpatel.farmtocity`, landscape only, Input System only, Collaborate proxy removed, the sim package referenced as `file:../../../sim` and compiling with no errors
