### US-066 Hire a day labourer

As the player, I want to hire a labourer from a neighbouring village for a day, so that I can handle busy periods.

- **Points:** 3 · **Priority:** Must · **Sprint:** S5
- **Acceptance:** Spec 006 ACs

**Tasks**

- [x] US-066.T1 `LabourPoolDef` by season
- [x] US-066.T2 `HireDayLabourer` command, paid upfront
- [x] US-066.T3 Task assignment: the labourers' hours join the Care pool, time-weighted ("tend the fields", ADR 0039 §5)
- [x] US-066.T4 Tests

### US-067 Regulars

As the player, I want labourers I hire often to ask to move to my village, so that my town grows from trust.

- **Points:** 2 · **Priority:** Should · **Sprint:** S6 (moved by ADR 0039)
- **Acceptance:** Spec 006 ACs

**Tasks**

- [x] US-067.T1 Regular threshold: seconds hired, 6 full day-equivalents (ADR 0039 §3)
- [x] US-067.T2 Move-in request event (`RegularAsksToMoveIn`; joins a full queue, always accepts, a new neighbour refills the roster; ADR 0041)
- [x] US-067.T3 Tests
