### US-073 Serialise the game

As the developer (Claude), I want the full game state saved and loaded byte-identically, so that nothing is ever lost or changed by saving.

- **Points:** 5 · **Priority:** Must · **Sprint:** S6
- **Acceptance:** Spec 007 ACs

**Tasks**

- [x] US-073.T1 Serializer choice (IL2CPP-safe): hand-written binary, one write path with the hash (`IStateWriter`), content ids in the header (ADR 0041)
- [x] US-073.T2 Schema version (and `SaveTooOld` until the playtest build)
- [x] US-073.T3 Round-trip property test
- [x] US-073.T4 Live `Sync` compaction and the replay-base checkpoint at the log cap (spec 007 §3.2)

### US-074 Safety save points

As the player, I want my town recovered automatically after a crash, so that I never lose my progress.

- **Points:** 3 · **Priority:** Must · **Sprint:** S6
- **Acceptance:** Spec 007 ACs

**Tasks**

- [x] US-074.T1 Atomic write with checksum (`SavePoints` over `IFileStore`)
- [x] US-074.T2 Rotating backups
- [x] US-074.T3 Auto-recovery and notice (the restored card; an unreadable town kept with a card, ADR 0041)
- [x] US-074.T4 Tests
